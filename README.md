## About Me

I'm a frontend-focused software engineer with 5+ years of experience building web applications across **AI, workflow automation, Web3, and product-driven platforms**.

My strongest focus is building clean, responsive, and maintainable user interfaces with **React, Next.js, and TypeScript**.
